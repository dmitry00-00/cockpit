# M17: локальное восстановление OCR-подписей и значков — 05.11.2026

## Реализация

- В режиме чистого растра подмешиваются только OCR-записи Toril с редакционно принятой ролью `feature`; фрагменты и GIS-reference не создают новые подписи.
- Подписи используют исходные пиксельные координаты. Это визуальный слой, он не добавляет записи мест в кампанию и не создаёт карточки.
- Для 633 распознанных растровых значков сравниваются координаты справочника: 190 совпадают с существующими местами в радиусе 5 px и исключены; 443 оставшиеся позиции рисуются простыми категорийными знаками.
- Загрузка из `content/maps/toril-ocr-classification.json` и `maps/ocr/toril-labels.json` разрешена только в Vite dev, для Toril и только в режиме очищенной карты. Классификатор по-прежнему исключён из пакетов/production assets; личный растр и OCR-снимок не копируются.
- Знаками представлены только координата и класс source icon; они не интерактивны и не утверждают существование самостоятельной сущности.

## Проверка

- Чистые функции проверены отдельным Vitest запуском: 15/15 тестов, включая фильтрацию принятых OCR-объектов и исключение повторных знаков справочника.
- `npx tsc --noEmit -p tsconfig.app.json` — успешно; `git diff --check` — успешно.
- CUA, текущий локальный сеанс, 802×672 CSS px, DPR 1; регион Sword Coast North, режим «Карта», масштаб 50 миль. DOM canvas подтвердил `data-raster-labels=3207`, `data-raster-icons=443`, всего 4 759 записей кандидатов подписей. Визуально видны подложка, восстановленные подписи и значки без отдельной панели/интерактивных мест.
- Стандартный `npx vitest run src/map/schemaLabels.test.ts --maxWorkers=2` дважды зависал до сбора тестов на общей конфигурации; остановлен. Изолированный конфиг без глобального setup завершился успешно.

## Остаток

Это локальное восстановление проверенных OCR-объектов, не полная приёмка M17. Нужно исправить видимые следы очистки по трудным срезам (дороги, фактура Great Dale/Chessenta, зубцы стены), проверить отображение остальных масштабов и сверить читаемость OCR-имён. Неоднозначные GIS-связи не назначались автоматически. Браузерная проверка была на узком окне; визуальная матрица остаётся открытой.


## Повторная приёмка OCR-слоя — 05.11.2026

CUA на локальном стенде: режим «Карта», регион Sword Coast North, кадр вокруг Great Dale / Impiltur, шкала 20 миль, окно браузера 980×690 CSS px. Переключены очищенный растр и оригинал при сохранённом кадре. На очищенном слое overlay показывал три явно склеенные/неполные записи: `ROAD` (12544,3424), `Fortress of Mat THEPRINCES ROADT` (12355,3535), `Filur LORD'SROAD` (12440,3657). В оригинале это отдельные картографические подписи, а не самостоятельные названия объектов. Добавлены три принятые редакторские классификации `fragment`; исходные OCR/GIS/L1 и пиксельные данные не менялись. Сборка классификатора в режиме `--check` подтвердила актуальность: 3 579 строк, 3 204 feature, 185 fragment, 190 GIS-reference.

После перезагрузки стенда три некорректные overlay-подписи исчезли; геометрия карты и кампания не менялись. В том же кадре остаются иные незавершённые подписи (`House of`, `COAST`) и видимые следы очистки самого растра; они не исправлялись без достаточного основания. Это локальная точечная поправка OCR-слоя, не приёмка очищенной подложки и не восстановление отсутствующих GIS-связей.
