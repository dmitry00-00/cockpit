# Мир и путешествия: проверка серии

24 выбранных оригинала в `design/art/world-and-travel-v1/manifest.json`:4 видовых образа,12 типов мест,8 объектов путешествия. Все созданы built-in image_gen; точные промпты и исходные пути в generation-log.json. Вторая версия лошади выбрана после исправления обрезанного уха; первая сохранена, но не поставляется как отдельный ассет.

Проверки: `npm run build:art` — успешно; `npx vitest run scripts/build-art.test.mjs --maxWorkers=2` —6/6; `npm run build` —exit0, включая check-art-delivery. Общая поставка87 иллюстраций,257 вариантов,2967918bytes. Оригиналы не попадают в поставку, реестр остаётся отложенным.

CUA, in-app browser,1280×720: галерея `/design/art/world-and-travel-v1/index.html` показывает24 карточки,168/168 изображений загружены, горизонтального переполнения нет. Скриншоты `world-travel-gallery-locations.png` и `world-travel-gallery-camp.png`.

На сливовом и светлом фоне предметы отделяются от поверхности. Башня/крепость и пещера/подземелье/шахта имеют разные основные формы. В32px мелкий декор теряется, гавань и город требуют подписи; эти изображения не заменяют служебные маркеры16–24px. У лошади на тёмном фоне контраст ниже; для мелкой служебной кнопки нужен отдельный упрощённый знак. Видовые лица — типовые авторские образы, не индивидуальные портреты и не универсальная внешность каждого представителя вида.

PNG alpha проверена отдельно Luna: `research/coordination/world-travel-alpha-audit.md`. Наличие alpha само по себе не доказывает качество всех краёв. Полная приёмка в рабочем интерфейсе, реальные entity mappings и другие семейства БА25 остаются открыты.
