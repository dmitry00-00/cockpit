# Фанделвер: краткие брифы для оставшихся портретов

Источник фактов: локальная разметка `research/content-phandelver/first-vertical.json` и паспорт `research/content-phandelver/source-passport.json`. Страницы ниже — страницы PDF источника, не печатная пагинация. В графе есть только краткие ролевые сводки; если конкретные видимые признаки не зафиксированы там, они оставлены на усмотрение художника. Не выдавать художественные решения за книжный канон. Направление: выразительная живописная фэнтези-иллюстрация, натуральные материалы, мягкий свет сверху слева, без рамок, текста, логотипов и интерфейсных знаков.

### Проверка границ

- Для конкретизации видов/пола использованы записи каталога `content/world/people/*.json`, без повторного чтения PDF. Возраст из `born` не переводился в годы, поскольку в паспорте `campaignYear` равен `null`. Elmar/Elmina оставлен открытым конфликтом: нельзя автоматически считать, что варианты взаимозаменяемы.
- В графе нет подтверждённых точных возрастов, цвета волос/глаз и большей части одежды; это намеренно оставлено художественному решению.
- Портрет Iarno предназначен для публичной идентичности и не раскрывает тайну, упомянутую в резюме узла.
- Источник — локальная русская версия `Lost Mine of Phandelver`, PHantom, 2015 (идентичность файла по SHA-256 указана в source passport). PDF и оригинальные иллюстрации не копируются в этот документ.
