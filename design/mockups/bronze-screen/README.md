# Бронзовая тема — мобильная компоновка

На любом размере окна мокап занимает доступную высоту. Внешняя страница не прокручивается целиком: карточка, карта и входящие остаются в пределах одного экрана, а длинное содержимое прокручивается внутри соответствующей панели. На ширине от 961 до 1150 px сохраняется компактная четырёхколоночная раскладка. При ширине до 960 px сверху остаются разделы и часы, ниже — горизонтальный ряд персонажей и карта; карточка раскрывается поверх карты. Кнопка «Карта» сворачивает карточку, а «Решения · 2» открывает входящие поверх рабочей области; `Esc` закрывает панель.

Широкая раскладка сохраняет отдельные области партии, карточки, карты и входящих. Данные и действия в этом этюде демонстрационные; файл не подключён к состоянию кампании.

Компоновка исправлена после замечания о длинной прокрутке страницы. После последнего изменения полный браузерный просмотр всех ширин ещё не выполнен, поэтому описание отражает реализацию и ожидаемое поведение, а не результат визуальной приёмки.
