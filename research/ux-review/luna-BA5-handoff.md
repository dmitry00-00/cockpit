# БА5 — передача Luna

## Что изменено

- Входящие в `src/pages/desk/ToolsPanel.tsx` сортируются на две последовательные группы: «Изменения мест и регионов» для предложений без `far` с масштабами `region`, `settlement`, `building`, `battle`; «Сводка мира» — для `far: true` и масштабов вне этого списка. Подпись объясняет, что это порядок по масштабу и метке, а не оценка срочности или доказательство географической близости; порядок внутри групп сохраняет исходный порядок `pending`.
- У каждой карточки видно, что решение требуется, и при наличии точной связи через `deltaTargets` — место или фракцию. Масштаб, причина и цепочка причины, исходное и предлагаемое значения показываются `WorldDelta`. Для дельт с патчем явно подписан результат принятия; для сообщений без патча указано, что принятие не меняет данные мира автоматически. Принятие/отклонение остаются вызовами `api.accept`/`api.reject`, отмена — действующим undo журнала.
- Экспорт журнала, открытие файла сессии, импорт контента и запуск новой сессии объединены в закрытое по умолчанию раскрытие «Кампания». Подтверждение «Стереть / Оставить» сохранено. Меню полностью отсутствует у игроков.
- `src/pages/DeskPage.tsx`: существующие callback-и операций остаются подключёнными к `ToolsPanel`; в `CharacterPathView` передаётся уже готовый `actor` для интеграции с planner-компонентом. Реализация planner не менялась.
- Обновлены тесты меню в `src/pages/DeskPage.test.tsx`; разрешённый root-ом кейс в `src/pages/desk/time.test.tsx` теперь открывает меню перед проверкой подтверждения сброса. Добавлен `src/pages/desk/tools.test.tsx`.
