# ПР2 — первый рабочий пеленг похода — 04.11.2026

## Реализовано

- В режиме «Поход» на плоской карте Toril появляется компас к выбранному пину.
- Пеленг считается по координатам карты от партии к целевому месту; шкала — градусы по часовой стрелке от севера, плюс одно из восьми направлений.
- Показатель подписан «прямо по карте»: это направление к цели по прямой, отдельно от маршрута по дорогам/точкам. Геодезическим азимутом результат не объявляется.
- На компас передаётся направление, откуда дует ветер. Для дневной погодной проекции добавлено детерминированное восьмистороннее направление из хеша дня; это описательное правило стола без механического эффекта.
- Стрелки цели и ветра различаются по стилю и имеют текстовое значение; штиль не рисует ложное направление.
- Управление и выбор пина остаются прежними. Это экранная проекция: навигация не создаёт событие кампании.
- Расчёт вынесен в `src/map/courseBearing.ts`; визуальный компас — `src/map/CourseCompass.tsx`; включение в панели похода — `src/map/WorldMap.tsx`.

## Проверки

- `npx vitest run src/campaign/weather.test.ts src/pages/desk/ClockBar.test.tsx src/map/courseBearing.test.ts src/map/WorldMap.test.tsx --maxWorkers=2` — 4 файла, 55 тестов прошли. В консоли WorldMap были существующие предупреждения о калибровке `toril-clean`.
- `npx tsc --noEmit -p tsconfig.app.json` — первый запуск нашёл неиспользуемый импорт в компасе; импорт удалён, повторная проверка прошла.
- `npx vite build --outDir /private/tmp/cockpit-p2-wind-20261104-r1 --emptyOutDir --manifest` — production-сборка прошла, 539 модулей; остались общие Rollup warnings о смешанных static/dynamic imports и крупных unrelated chunks.

## Не готово для зачёта ПР2

- Направление ветра общее для дня кампании, не локально для координат партии; модель не имеет реальных метеоданных и остаётся правилом стола.
- Не отображается отдельный ручной курс путешественника и снос ветром; стрелка ветра не меняет маршрут или скорость и только показывает описательную модель.
- Нет эталонного GLB компаса, fallback-изображения или приёмки компаса как 3D-предмета.
- Проверено в jsdom и по исходной геометрии; браузерный CUA просмотр в этом проходе недоступен.

Итог: есть ограниченная рабочая интеграция пеленга к точке назначения; ПР2 остаётся открытым.
