## Выбранный год и места в снимке — 19.11.2026

Линза карты объединяет ссылки на места из событий статей-годов и слоя летописей;
строки публикаций не становятся маркерами событий. JSON выгрузка имеет схему
`cockpit.canon-snapshot/2` и поле `placeMentions` с именами, ссылками и ID/годами
событий из выбранного окна. Эти годы датируют только записи событий, а не основание,
существование или принадлежность мест. Записи NPC и организаций без явных дат
сохраняют `undated`.

## Граница редакторской разметки

Рубрика определяет основную тему для фильтрации, а не добавляет сведения о мире.
Источник — существующие тексты Forgotten Realms Wiki и их ссылки/цитирования,
CC BY-SA 3.0; редакторские решения отделены от исходных рубрик. Новых дат,
механик и канонических утверждений нет. Исходные типы имеют приоритет.

Используется закрытый список `ChronoKind` из `src/world/chronology.ts`.
Политика включает основание и управление городами/державами; организации —
гильдии, ордена и учреждения. Переселения означают движение населения.
Природа требует физического изменения среды; Realmspace — космического события.
Упоминание Moonsea или лунных эльфов само по себе ничего не классифицирует.
«Изданное об этом годе» относится к публикациям вне мира, а не изготовлению карт.

22 редакторских фрагмента оставлены в «прочее»: недостаточно контекста для более
точной темы. Это явная рубрика с основанием, а не незаполненный тип. Вместе с
наследованными исходными рубриками «прочее» содержит 44 записи.

В интерфейсе у редакторских записей раскрывается основание и буквальный фрагмент
источника. Канон и журнал кампании остаются отдельными секциями.

## Защита от устаревания

SHA-256 учитывает исходное содержание записи, включая даты, ссылки, источник и
`same`; идентификатор исключён, чтобы перенумерация импортёром не ломала разметку.
Наследование также проверяет содержание и тип связанного события статьи-года.
Новые/изменённые записи остаются без типа до проверки. Автоматического угадывания
по словам или назначения «прочее» по умолчанию нет.

Проверка:

```sh
npm run check:chronology-classification
python3 -m unittest discover -s scripts -p test_chronology_classification.py
npx vitest run src/world/chronologyClassification.test.ts src/world/chronology.test.ts src/pages/desk/chronology.test.tsx --maxWorkers=2
```

После изменения проверенного реестра: `npm run build:chronology-classification`.
Исходный импортёр использует тот же модуль `scripts/chronology_classification.py`.
Полный повторный импорт XML в этой задаче не выполнялся; проверены чистые входные
записи, повторное применение, изменение источника и связанной канонической записи.
