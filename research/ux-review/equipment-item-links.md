# E7: карточка предмета из снаряжения

01.11.2026. SheetEquipment использует существующий OpenEntityContext: известные SRD-предметы открываются по item:<id>, количество и отметка надетого остаются в списке. Неизвестный id и поверхность без обработчика сохраняют текст без ложного перехода.

Переход из линии партии сворачивает тела карточек и показывает инспектор сущности. Возвращение через корешок сохраняет вкладку и поле хитов. Открытие участника по ссылке раскрывает его карточку; смена вида явно сворачивает партию, без отложенного эффекта, который раньше мог стереть только что открытого участника.
