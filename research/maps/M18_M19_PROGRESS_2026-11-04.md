## M18 — общая поверхность

- `surfaceProjection.ts`: CPU/GLSL модель сферы, плоскости и смешения; обратная проекция, ограничение наклона камеры ±75°. Это ограничение интерфейса, не характеристика планеты.
- `tilesGl.ts`: одна программа проекции для тайлов растра и схемы, адаптивная сетка, clipping обратной стороны, мипмапы, отмена загрузок, оценки текстур/сеток и необязательный GPU timer.
- `surfaceTiles.ts`: обход и отсечение иерархии вместо перечисления всей сетки на высоком LOD. Тест LOD22 проверяет менее500 выходных тайлов и менее5000 посещённых узлов; sampled coverage отдельно проверена при трёх проекциях. Это не математическое доказательство полноты всей карты.
- `SurfaceHost.tsx`: сессия поверхности живёт вокруг `LevelZone`; при глобус → карта переносится один canvas с контекстом, программой и готовыми текстурами. Старые pending jobs отменяются без очистки готового кэша. Проверены StrictMode replay, устаревший cleanup и смена карты.
- `SphereSurfaceLayer.tsx` используется глобусом и плоской схемой/растром планеты. Для карт без географической маски остаются прежние слои, использующие тот же базовый тайловый рендерер. Нет утверждения, что все поверхности космоса уже переведены на эту сессию.
- `surfaceZoom.ts`: сохранение точки под курсором через согласованную модель центра/широтного масштаба; встроено в анимацию колеса. Сфера использует непрерывный радиус вместо округлённого числа клеток.

## M19 — первый авторский план

В приложении на уровне поселения появилась кнопка «Черновик поселения». У Neverwinter открывается **отдельная авторская геометрия**, не копия канонического города. Канонический план по умолчанию остаётся приоритетным; это проверено `levelMap` тестом после принятия авторского снимка.

Путь: поселение → выбрать здание → комнаты и сетка5футов → собственный PNG/UVTT. Генератор `m19-city-v1`, `table-rule`, детерминированный seed от setting/map/place/version. Это собственный прямоугольный layout; тип/население/описание канонического города ещё не формируют его геометрию. Внешние генераторы и полноценный редактор не заявлены.

Просмотр/генерация не пишут событий. «Предложить закрепление» создаёт предложение; только `WORLD_DELTA_ACCEPTED` с `settlementPlan` сохраняет полный снимок в `world.settlementPlans`. Повторное открытие принятого плана не запускает генератор заново. Проверены предложение без активации, принятие, сериализация/перезагрузка, undo/redo, восстановление предыдущего снимка после замены, отказ для геометрии другого места. Player DTO не содержит seed/геометрию. Новые актёры, сцены и места из зданий автоматически не создаются.

CUA1920×1080: выбран building01, три комнаты; исправлены чрезмерно крупные подписи и видимость сетки поверх заливки. CUA1280×720: центральная область1184×408 CSSpx, горизонтального/вертикального переполнения контейнера нет; часы доступны по hit-test. В малом окне детали карты нуждаются в дальнейшей UX-приёмке; названия комнат дублируются читаемым списком.

### Экспорт и MapTool

Официальный [DungeonDraftImporter на commit9681fb5](https://github.com/RPTools/maptool/blob/9681fb5d2b649ced17763828254cc54cdfb4903a/src/main/java/net/rptools/maptool/client/utilities/DungeonDraftImporter.java) прочитан целиком локально из первичного GitHub raw. Исправлены обнаруженные расхождения: `format=0.2` (импортёр допускает0.2/0.3, а не2), raw base64 PNG без dataURI, целое `pixels_per_grid`; LOS — массив путей `{x,y}`, двери — `portals.bounds` и `closed`. Дверные промежутки исключаются из обычных стен, их закрытость передаётся порталами. Экспорт `.dd2vtt` не содержит канонический растр или личный журнал кампании.

Реальный файл скачан кнопкой из браузера. JSON225799bytes; PNG1552×1856;8px/grid;578 LOS paths;107 portals. Проверены base64, PNG signature, CRC всех chunks и успешная zlib-декомпрессия IDAT. Это проверка поставленного файла, не только синтетической PNG-шапки из unit tests.

Первый файл реально импортирован в MapTool1.18.7 владельцем. Затем обнаружено ограничение `Grid.MIN_GRID_SIZE=9`: исходные8px/grid были подняты импортёром до9 (подтверждено панелью сетки). Экспорт исправлен на10px/grid с лимитом4096px; новый файл PNG1940×2320,578 стен,107 порталов, CRC и IDAT проверены. Повторный импорт через CUA дошёл до параметров карты:10px/grid и5.0 единиц/клетку. При повторной привязке прочитано главное окно settlement-10px; владелец затем подтвердил совпадение стен и дверных проёмов. Визуальная проверка импорта принята с его ручным участием. Q17 остаётся открытой: обмен токенами/хитами/состояниями не проверялся.
