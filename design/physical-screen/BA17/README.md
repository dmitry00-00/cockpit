# БА17 — печатный макет временного аксессуара

Комплект содержит два A4 SVG-листа для ручной сборки механической панели «астролябия + часы Харптоса». Все компоненты пассивные, без электроники.

## Печать

Печатать `BA17-print-1-base.svg` и `BA17-print-2-moving-parts.svg` на A4 при 100%, без подгонки. До резки проверьте квадрат 50 × 50 мм (допуск ±1 мм). Если размер отличается, отключите масштабирование драйвера печати и проверьте повторно.

## Сборка

Основание вырезать по прямоугольнику 190 × 145 мм и наклеить на картон 1–2 мм. Пробить центры циферблатов Ø3 мм. Вырезать две стрелки и четыре шайбы; каждую ось собрать как «шайба → стрелка → шайба → разрезная канцелярская заклёпка». Заклёпки не затягивать до блокировки вращения. Под основание наклеить четыре нескользящие точки Ø8 мм.

Список месяцев, порядок праздников и календарные подписи формируются из `content/calendars/harptos.json` командой:

```sh
python3 design/physical-screen/BA17/generate_templates.py
```

Распечатанный макет не синхронизируется с приложением. Любое продвижение времени нужно отдельно внести в DM Cockpit.
