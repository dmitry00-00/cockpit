## Контракт (зафиксирован для первой реализации)

```tsx
import type { ReactNode } from 'react';
export interface PartySpreadItem {
  id: string;
  name: string;
  spine: ReactNode; // компактное представление без вложенных кнопок/ссылок
  card: ReactNode;  // готовая карточка, её функциональность принадлежит вызывающей стороне
}
export interface PartySpreadProps {
  items: readonly PartySpreadItem[];
  selectedId?: string;
  onSelect: (id: string) => void;
  expanded: boolean;
  onExpandedChange: (expanded: boolean) => void;
  context?: ReactNode; // общие сведения под карточками; пустое не рисовать
  className?: string;
}
export function PartySpread(props: PartySpreadProps): ReactNode;
```

Не импортировать engine/store, не считать хиты/ресурсы, не создавать события. Данные уже
подготовлены вызывающей стороной с учётом аудитории. Никаких новых изображений/зависимостей.

## Поведение

- Горизонтальная линия корешков и кнопка «Информация о партии», показывающая общее число.
  aria-expanded/aria-controls и понятные русские подписи. Корешок выбирает персонажа через onSelect.
- Нажатие информации раскрывает до6 карточек одновременно; повторное нажатие сворачивает.
  Карточки должны оставаться читаемыми, а не ужиматься в шесть столбцов любой ценой.
  На узком экране допустимы перенос/локальная прокрутка; общий горизонтальный scroll недопустим.
- Если участников больше6 — доступная пагинация/переключение набора без потери участников.
  Выбранный участник должен быть достижим; изменение массива не оставляет пустую последнюю страницу.
- Под раскрытыми карточками — context. Не выдумывать «инвентарь повозки», состояние лагеря
  и значения из отсутствующих данных: компонент получает готовый ReactNode.
- Сворачивание не должно сбрасывать локальные раскрытия/черновики готовых карточек.
  Продумать сохранение mount карточек; скрытое содержимое отсутствует в accessibility tree/Tab-порядке.
- Клавиатура, видимый фокус; Esc сворачивает раскладку, но не перехватывает Esc дочернего
  диалога/поля/уже обработанного события. Для 0 участников — корректная компактная поверхность.

## Последнее уточнение02.11.2026
Индивидуальная inline-итерация отклонена. Только общая кнопка раскрывает/сворачивает все до6 текущей страницы. В collapsed используется реальный CharacterCardSpine, в expanded — полная карточка в том же keyed slot, без дополнительной строки навигационных спинов над полными картами.
