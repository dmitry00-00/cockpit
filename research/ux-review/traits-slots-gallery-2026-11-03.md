# Особенности и слоты: проверка серии

19 выбранных новых оригиналов: шесть слотов экипировки и 13 групп особенностей. Три готовых Kimi-предмета используются для шеи, брони и оружия. Карта `design/art/traits-and-slots-v1/coverage.json` содержит все 22 роли; повторное использование не считается новой генерацией. `kind-tool-v2.png` выбран после удаления светлого ореола, первая версия сохранена отдельно.

CUA, in-app browser, 1280×720: галерея `/design/art/traits-and-slots-v1/index.html` содержит все 22 роли, 176/176 изображений загружены, горизонтального переполнения нет. На двух поверхностях просмотрены пробы 32/48/64 px. Скриншоты: `traits-slots-equipment.png`, `traits-slots-traits.png`.

Кольцо, пояс, перчатки и сложенный плащ имеют разные основные формы. Капюшон Скрытности не используется для слота плаща. Зрение (глаз с полумесяцем) отличается от чувств (ухо с волнами), сопротивление — от спасброска. У ауры на светлом фоне контраст ниже; подписи обязательны. Символ сопротивления не утверждает устойчивость конкретного персонажа именно к огню. Смена формы — авторская метафора, не изображение конкретного превращения.

Хеши, размеры и alpha 19 выбранных PNG независимо проверены Luna: `research/coordination/traits-slots-alpha-audit.md`. В source registry сохранены промпты и происхождение; автоматической подстановки в рабочий интерфейс нет.

`npm run build:art` — успешно. `npx vitest run scripts/build-art.test.mjs --maxWorkers=2` — 6/6. `npm run build`, включая проверку поставки — exit 0. Общая поставка: 178 иллюстраций, 530 WebP, 3 967 166 bytes. Логи: `/private/tmp/cockpit-art-178-tests.log`, `/private/tmp/cockpit-art-178-build.log`.

Серия закрывает производство этих 22 ролей. Приёмка их в рабочем UI и другие семейства БА25 остаются открыты.
