# M13: точное покрытие и проверенные поправки

Работа по активной цели M13 → M17/M16 → M18 → пилот M19. Цель остаётся активной;
M13 принята после проверки полного покрытия, редакторских решений, runtime-загрузки и трёх контрольных мест. Это не завершение общей цели.

## Исправление первичного аудита

Первичное сравнение только OCR и L1 было недостаточным и ошибочно утверждало
отсутствие Ordulin. Сверка всех источников дала:

| Маршрут записи | Количество | Доказательство |
|---|---:|---|
| L1, done | 3056 | уникальный OCR id и строка L1 |
| L1, review | 7 | уникальный OCR id, требует приёмки |
| Уже связано с GIS | 190 | буквальное совпадение name/ocr + ближайшие координаты не дальше 42 px |
| Прежний fragment-фильтр | 326 | запись с тем же id и status fragment в registry |
| Не учтено ни одним маршрутом | 0 | полный проход 3579 исходных записей |

190 подписей не требуют повторной классификации как новых мест. Среди 326
фрагментов есть настоящие названия: прежний фильтр отвергал одиночные слова с
маленькой первой буквой, включая прилипший кружок `o` перед именем города.

`scripts/audit_m13.py` воспроизводит сверку и сохраняет полный перечень с
происхождением и SHA-256 входов в `m13-coverage.json`. `--check` обнаруживает
устаревший отчёт; тесты покрывают разные маршруты, ложное совпадение имени и дубли.
`accountingComplete` означает полноту учёта, а не завершённую классификацию.

## Принятые поправки справочника

В пакет FR добавлен внутренний слой `content/maps/toril-raster-corrections.json`.
Он применяется после GIS/карточек, сохраняет стабильный ID, текст карточки и ссылки.

- Teziir: GIS хранил имя `Tezilr`; OCR — `oTeziir`. Исходный растр подтверждает
  Teziir и маркер города (10733,4108). Имя исправлено для отображения, `Tezilr`
  сохранён как поисковый alias, класс Town оставлен из GIS. Описание не сочинялось.
- Selgaunt: карточка использовала приблизительную позицию (11480,3927). На растре
  видна подпись Selgaunt и белый кружок (11500,3887); тот же кружок сохранён в OCR
  marks. Поправка снимает approx и сохраняет существующую карточку.
- Ordulin: уже существует в places и cards, ID
  `9333b8a7-7e95-46bb-b0bf-a2b754803c61`, позиция (11586,3723). Новая дублирующая
  запись не создавалась.

Это справочник мастера, не активация места или перемещение партии в event log.
Подписи чистой подложки отдельным генератором в этом шаге не пересобирались.

## Принятый редакторский слой

`m13-editorial-review.json`: 333 принятых решения (326 прежде отсеянных fragment +
7 L1 review). Все срезы просмотрены: Codex разобрал 101 первоначально неясную запись,
Luna проверили остальные feature-кандидаты и 135 фрагментов; спорные случаи повторно
рассмотрены Codex на расширенном окне. Итог: 151 feature и 182 fragment. Ни одной
записи unreadable/review в принятом слое нет. `publish: false` означает запрет
автоматически создавать новые места, а не незавершённость классификации.

Обрывки THE/SEA/Mts внутри составных подписей, части наклонных надписей и склейки
нескольких мест имеют отдельную роль fragment. Они не получают фиктивный
географический тип other и не становятся самостоятельными топонимами. Полные
названия восстанавливались только по действительно видимой подписи. Это
картографические редакторские рубрики, не утверждения о состоянии мира на год.

`build_m13_classification.py` объединяет 3056 принятых legacy L1, 333 редакторских
решения и 190 GIS-связей. Выход `content/maps/toril-ocr-classification.json` содержит
ровно 3579 уникальных исходных записей: 3207 feature, 182 fragment, 190 GIS-reference.
При изменении текста/координат/метаданных OCR отпечаток редакторского решения
перестаёт совпадать и сборка разметки завершается ошибкой. Новые записи, неизвестные
типы, дубли и непроверенные решения не проходят. Режим `--check` сравнивает артефакт
с текущими входами. Исходные статусы семи строк L1 оставлены для истории; принятые
решения живут в отдельном слое. Старое `legacyL1QueueComplete: false` в аудите
описывает этот неизменённый источник, а не состояние окончательной разметки.

Gazetteer загружает классификацию через пакетный реестр и применяет редакторские
типы к существующим OCR-карточкам. Он не удаляет полную карточку, подтверждённую
источником, из-за того, что исходный OCR захватил лишь часть её имени; текст и
источники сохраняются. Массовой публикации новых сущностей нет. Повторная очистка
растра и восстановление всех видимых подписей остаются M17.

Команды:

```sh
python3 scripts/audit_m13.py --check
python3 scripts/build_m13_classification.py --check
python3 -m unittest discover -s scripts -p 'test_*m13*.py'
```

начальный загрузочный кусок.
