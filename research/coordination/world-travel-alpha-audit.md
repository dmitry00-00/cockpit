# World and travel PNG alpha audit

Проверено **24 выбранных семантических оригинала** из `design/art/world-and-travel-v1/manifest.json`: 4 ancestry, 12 мест, 8 образов путешествия/лагеря. Для верховой езды манифест выбирает `travel-mount-v2.png`; `travel-mount.png` — прежняя отвергнутая версия framing, проверена отдельно и не считается 25-м ассетом. Сравнительный Kimi baseline также вынесен отдельно.

Анализатор в `/private/tmp/png_alpha_audit.py` использует только Python standard library (`struct`, `zlib`), распаковывает PNG scanlines с фильтрами. Все проверенные исходники — PNG 8-bit RGBA, non-interlaced. Изображения не изменялись. Browser gallery evidence сообщает, что на композитах нет матового прямоугольника; этот отчёт измеряет пиксели, а не заменяет этот визуальный просмотр.

Для каждого изображения: `α=0 / 1–254 / 255` — точные количества пикселей по всему холсту; `≥240` и `≥250` — доля непустых пикселей (α>0), включая указанную границу; median — стандартная медиана alpha непустой области (для чётного числа усредняются два центральных значения). BBox координаты включительные; поля `[L,R,T,B]`.

## Выводы

- У всех 24 выбранных оригиналов есть настоящие прозрачные (`α=0`) и частично прозрачные пиксели. Большая доля частичных alpha сама по себе не означает «прозрачный объект»: медиана непустого alpha — 252 или 253; **95,8%** непустых пикселей имеют α≥240 и **94,5%** — α≥250. Полностью непрозрачный внутренний цвет не обязателен для painterly края/стекла.
- По порогу α>0 bbox касается границы холста у 23/24 исходников; такие пиксели могут иметь alpha=1. По порогу α≥128 у выбранных 24 файлов есть поля минимум 11px. Отвергнутая `travel-mount.png` касалась верхней границы (T=0), что согласуется с пометкой об обрезанном ухе. Выбранная `travel-mount-v2.png` имеет поля `[201, 169, 118, 149]` и заменяет v1; это один смысловой ассет.
- Сравнительный мастер `design/art/kimi-production-v1/class-fighter-v1.png` (манифест: approved style / working-direction, малые размеры и UI остаются pending) имеет median α=253, α≥240 у 96,7% и α≥250 у 95,0% непустой области. Выбранные world/travel файлы близки по распределению; не следует «чинить» их alpha-порогом.
