При получении уровня можно необязательно заменить один известный каталоговый заговор другим вариантом из списка книги; сохранённый локальный план принимает и восстанавливает эту замену. При применении лист сохраняет выбранные заговоры, лимит подготовки, ячейки и заклинания; отмена и повтор используют существующий снимок уровня.

Это только срез уровня. Полный список заклинаний 1–5 кругов не подключён; заменять отсутствующие книжные записи догадками или UA не стали. В этой итерации тесты, typecheck и браузерная приёмка не запускались; выполнение изменения не считается принятым.

## Реализовано

`SpellPlan` теперь содержит отдельные значения прироста за переход уровня. Для классов `known` прирост берётся из дельты таблицы класса; для книги волшебника — шесть заклинаний на 1-м уровне и два на каждом следующем; для `prepared` прирост записываемых заклинаний равен нулю, а новые заговоры остаются отдельным выбором. Это устраняет зависимость выбора волшебника от числа уже занесённых в книгу заклинаний.

Форма показывает прирост заговоров подготовленных заклинателей и поясняет, что при повышении здесь не выбирается новый список подготовки. Текущий список сохраняется, `preparedLimit` пересчитывается из итоговой характеристики после ASI. Окно черты теперь отображает все импортированные тексты эффектов с названиями категорий; рядом с эффектом, имеющим точный адаптер, показывает рассчитанный результат, а остальные помечает как неавтоматизированные.

Добавлены регрессионные проверки для таблиц разных типов заклинателей, волшебника с книгой длиннее базового числа и жреца с новым заговором, сохранением подготовленных заклинаний и обновлением лимита после ASI.

## Точечный эффект черты «Крепкий»

Для локальной записи `krepkiy` добавлен адаптер к `effects.hp`: при выборе на уровне N максимум хитов увеличивается на `2 × N`, а последующие уровни добавляют ещё 2. В `featEffects.ts` адаптер включается только при совпадении ID, источника `book`, пустого поля `text` и полного текста эффекта HP; если строка данных изменится, она перестанет применяться. Этот feat нельзя выбрать повторно. Событие повышения сохраняет feat с provenance и включает рассчитанную прибавку в journal entry. Установленное правилом стола увеличение текущих HP на величину прироста максимума применяется так же, как для обычного прироста уровня.

Официальный D&D Beyond перечисляет Tough из Player’s Handbook (2014, Legacy) с эффектом +2 HP на персонажный уровень; Basic Rules 2014 ограничивает повторный выбор одной чертой, если её описание явно не разрешает иное. Точная формулировка взята из импортированной записи компендиума, где издание книги не указано: [D&D Beyond — Feats](https://www.dndbeyond.com/feats), [Basic Rules 2014 — Feats](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/customization-options).
