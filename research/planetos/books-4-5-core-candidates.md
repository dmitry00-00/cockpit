# Ключевые кандидаты для книг 4–5: широкий индекс

**Назначение:** дельта-аудит следующей волны для основной книжной саги. Это 30 предложений: максимум 15 для каждого романа. Это не добавленные карточки и не измерение покрытия; перед интеграцией повторно сверить ID, карточки и факты с выбранным изданием.

**Ограничения источника:** AWOIAF использован только как вторичный указатель глав, участников и мест. Его страницы не заменяют первичный текст; пересказы могут быть неполными, а часть страниц ссылается на старые вклады участников. Все краткие описания ниже переформулированы. Не выводить абсолютные даты из порядка глав. Производные записи должны сохранять атрибуцию/CC BY-SA; пакет внутренний.

Все пункты имеют статус `secondary-indexed-partial`. Книга, глава и ссылка — источник обнаружения/локатор, а не доказательство полноты. Связи в скобках — уже существующие ID, если они есть; другие новые пункты помечены как кандидаты.

## Как использовать список

1. Сверить ID с пакетами и алиасами; добавлять только отсутствующие записи. Кандидаты не должны ссылаться на другие новые карточки, пока они не интегрированы.
2. Для каждого факта хранить книгу/главу и различать «появился/упомянут», «произошло/план/сообщение/слух». Повторяющиеся персонажи сохраняют общий ID, но факты имеют отдельные locators раскрытия.
3. Завести отдельные chapter ledgers для AFFC и ADWD. Этот shortlist не является знаменателем покрытия: нужен полный очищенный реестр глав.
4. Пока граница книги и главы не фильтрует поля, связи, поиск и события до выдачи player-view, весь список остаётся внутренним GM-материалом.
5. Перед статусом «проверено» сверить каждую запись по выбранному роману/переводу и сохранить рабочее русское имя отдельно от стабильного английского ID.
