# БА26 — выбор встроенного портрета в редакторе

## Готово

- В редакторе-карте персонажа появился доступный с клавиатуры выбор: «Без портрета» или единственный одобренный встроенный вариант «Bo · живописный портрет».
- Выбор явно меняет черновик. Предпросмотр использует существующий `PortraitImage` с ленивой загрузкой; отсутствие выбора отображает подпись «Без портрета».
- Типизированное поле черновика передаётся через `toSpec` в `PcSpec`, затем через `pcActor` в снимок листа. Выбор без портрета опускает поле.
- Целевой тест проверяет preview, очистку выбора, создание актора через `ACTOR_SPAWNED` и восстановление ссылки при replay журнала.

## Проверка

`npx vitest run src/pages/editor/CharacterEditor.test.tsx src/pages/editor/draft.test.ts --maxWorkers=2 --reporter=dot` — 2 файла, 31 тест прошёл.

## Границы

Каталога и других портретов пока нет: в интерфейсе намеренно предлагается только `bo-portrait`. Портрет не выбирается автоматически по имени или id персонажа. Пользовательские файлы Q12 и редактор их загрузки не затрагивались. Генераторы и сборка не запускались.
