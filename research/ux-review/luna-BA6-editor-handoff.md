# БА6 — часть редактора персонажа (Luna)

## Сделано

- В шаге «Класс» варианты теперь используют читаемый текст с переносом и большей высотой кнопки вместо обрезания названий. Размер шрифта не уменьшался.
- В нижней полосе редактора итог подписан как «Обязательных выборов осталось: N». Счётчики шагов и секций уже существовали и сохранены; детализация по-прежнему раскрывается там же.
- При смене расы, подрасы, класса или подкласса появляется сообщение о действительно сброшенных данных согласно `withRace` / `withSubrace` / `withClass` / `settle`. Смена класса из обоих мест — шага и карты — охвачена.
- Изменения остаются в черновике. Кнопка «В партию» по-прежнему вызывает создание только при готовом листе; просмотр дерева класса не создаёт актёра и сохраняет фильтр источников.

## Проверка

`npx vitest run src/pages/editor/CharacterEditor.test.tsx src/pages/editor/draft.test.ts --maxWorkers=2` — 2 файла, 30 тестов прошли. Добавлен тест целостности названия класса и объяснения сброса при смене класса.

## Ограничения / оставшаяся часть БА6

- Визуальная проверка в браузере не выполнялась; её делает root после интеграции.
- Подсказка о сбросе сообщает типы сброшенных решений, а не перечисляет каждое значение по имени.
- БА6 в целом не закрыта: остаются живописная графика/карточки и общая визуальная приёмка по окнам и доступности.

## Приёмка видимости сообщения

После браузерной проверки сообщение сброса перенесено из прокручиваемого тела шага в фиксированную область средней колонки. Оно не зависит от `scrollTop` и не прокручивает страницу. Тест дополнительно проверяет, что `role=status` находится вне прокручиваемого региона. Повторная проверка реального расположения в браузере ожидает интеграционную приёмку root.
