# M20 — сортировка по одной оси приоритета, 24.11.2026

`sortByPriority()` теперь сравнивает только выбранную пользователем оценку: `world` либо `table`. При равных оценках порядок разрешается прямым лексическим сравнением ASCII `id` через `<`/`>`, без `localeCompare()` и без использования второй оси. Tie-break поэтому одинаков во всех пользовательских локалях. Это применяется к сортировке маршрутов и очереди пробелов и приводит реализацию в соответствие с подписью интерфейса «не смешивает её со второй».

Оценки, их хранение, исходные данные и порядок без равенств не менялись; tie-break по ID детерминирован и не приписывает маршруту или пробелу дополнительную важность. Это исправляет только логику сортировки, не географическую точность M20.

Код изменён только в `src/map/m20MapRegistry.ts`; этот отчёт описывает срез. Статически просмотрен вызов общей сортировки для маршрутов и пробелов. Tests, typecheck, browser, planner и export не запускались.
