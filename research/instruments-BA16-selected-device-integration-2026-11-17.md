# БА16 — интеграция часов Харптоса и астролябии

Дата: 17.11.2026. Владелец выбрал для общей оболочки два представления времени: часы Харптоса и астролябию. Изменения ограничены интерфейсом `ClockBar`; модель кампании и события не менялись.

## Что подключено

- В одном модальном окне «Управление временем» мастер переключается между двумя выбранными режимами: «Часы Харптоса» и «Астролябия».
- Компактный циферблат Харптоса остаётся постоянной кнопкой полосы часов: показывает текущее время и фазу, открывает окно управления. В режиме Харптоса видны полный циферблат 160 px, календарь, дата, лунные фазы и праздники.
- В режиме астролябии показываются 340 px прибор, плита точного времени/даты и годовая линза. Обычные темп, числовой шаг и отдых остаются в той же оболочке.
- Оба пути продолжают пользоваться штатным `onStep`/`onStepAtTempo`: новый тип события не вводился, undo остаётся у event log. Переключение календаря/астролябии — состояние интерфейса, оно не меняет кампанию.
- Режим песочных часов убран из переключателя и `ClockBar`: пользователь выбрал часы Харптоса и астролябию. Сам компонент `SandglassTimer` не удалялся из библиотеки компонентов.
- У переключателей сохранён `aria-pressed`; циферблат Харптоса имеет доступное имя со временем и фазой; астrolabe-контролы остаются клавиатурно доступными по существующей реализации.

## Изменённые файлы

- `src/pages/desk/ClockBar.tsx` — пара режимов в общей оболочке; удалена ветка песочных часов.
- `src/pages/desk/ClockBar.test.tsx` — проверка двух режимов, активного состояния часов Харптоса, доступного циферблата, отсутствия третьего режима и сохранения отдыха.

## Проверки и ограничения

- `git diff --check -- src/pages/desk/ClockBar.tsx src/pages/desk/ClockBar.test.tsx` — ошибок форматирования не сообщил.
- `npx vitest run src/pages/desk/ClockBar.test.tsx --maxWorkers=2` — Vitest вывел `RUN`, около 30 секунд не сообщал о старте/результате теста; остановлен, результат не получен. После этого добавлена финальная регрессия сохранения формы отдыха в режиме часов Харптоса; итоговая версия тестового файла не прогнана.
- `npx tsc --noEmit -p tsconfig.app.json` — typecheck не проходит по существующим ошибкам: два присваивания `A5ePrestigeProfile` в Immer draft в `src/engine/reduce.ts` и отсутствующая метка `A5E_PRESTIGE_UPDATED` в `src/pages/desk/helpers.ts`. Ошибок в изменённых `ClockBar` файлах не указано.
- Попытка открыть локальный Vite-стенд завершилась `listen EPERM` на `127.0.0.1:5180`; браузерную проверку, узкий viewport, видимое focus-состояние и screenshot получить не удалось. Команда `npm run dev` выполнила штатные theme/icon/art build-скрипты до отказа порта; целевые сгенерированные пути не показывают изменений в Git status.
- Runtime-замер кадра/CPU/GPU/памяти и повторный production chunk замер не выполнялись. Значения из отчёта интеграции 04.11 — только исторический baseline, не результат этого изменения.

Итог: оба выбранных прибора доступны в общей оболочке времени и сохраняют существующий событийный контракт. БА16 остаётся открыта до браузерной приёмки на рабочем и узком размере и актуального измерения производительности.
