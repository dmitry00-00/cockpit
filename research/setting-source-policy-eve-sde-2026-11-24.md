# IS1 — EVE Static Data Export: source and rights boundary

**Reviewed:** 2026-11-24  
**Use in Cockpit:** reference only; no download or import

## What the official sources establish

CCP's developer documentation describes the Static Data Export (SDE) as static EVE game data, including map data, served through the SDE API. The Developer License Agreement describes `Game Data` as material CCP makes available for developer applications. Its stated purpose is a non-commercial, non-profit application used solely to enhance EVE players' enjoyment; it expressly excludes an application that does not support a player's use of EVE. The license grant is limited to use within an application for that purpose.

- [CCP Developer Documentation — Static Data](https://developers.eveonline.com/docs/services/static-data/)
- [CCP Developer License Agreement](https://developers.eveonline.com/license-agreement)

## Project decision

Cockpit is not currently an EVE companion. On a conservative reading of the published agreement, it does not establish permission to use SDE data in Cockpit. This records the project's current scope decision; it is not a finding that separate written permission is impossible or that every SDE use is categorically prohibited.

Keep the official documentation links as bibliography only. Do not download, ingest, redistribute, or generate Cockpit content from SDE records unless the owner selects EVE as a setting and the applicable terms or separate written permission are reviewed for that use. No SDE data was downloaded or imported for this review, and no agreement was accepted through an SDE download.

## Open owner decision

The candidate list separately names **EverQuest** and notes that an earlier spelling, “evequest,” may have meant EverQuest or EVE Online. This review does not select EVE Online as the next pilot. The intended candidate and its wiki/source remain for the owner to choose; IS1 remains open for the other listed settings.
