# Каталог записей SRD 5.1

Дата среза: 21.11.2026.

## Модель

`src/rules/srd/catalog.ts` сводит классификацию локальных SRD-записей в один индекс. Запись получает устойчивый ID, тип, заголовок раздела книги, `sourceRef` — файл плюс ключ исходной записи — и явные поля источника, редакции (`D&D 5e / 2014`), лицензии (`CC BY 4.0`) и слоя (`rules`). Полный текст не дублируется. Другие редакции и книжные/HB-записи в этот индекс не попадают.

Вкладка «Каталог SRD» в компендиуме фильтрует индекс по типу и ищет по имени, ID и разделу. Загружает каталог отдельным chunk. Классификация не означает, что игровая механика записи уже автоматизирована.

Восемнадцать навыков и шесть характеристик остаются в локальном каталоге с теми же устойчивыми ID, но их описания и связи теперь снимками импортируются из разрешённых ресурсов API в `content/srd/skills.json` и `content/srd/ability-scores.json`. Каталог ссылается на соответствующие строки снимков. То же сделано для девяти мировоззрений, 15 состояний и десяти действий: описания и имена идут из `alignments.json`, `conditions.json` и `actions.json`; существующая русская разметка `kind`, `label` и поведение в движке остаются отдельными локальными данными.

Атрибуция лицензии остаётся в `src/rules/srd/LICENSE.md`.

## Граница приёмки

Это единый классифицированный каталог **текущего локального корпуса**, но не доказательство, что локально представлены все записи книги SRD 5.1. 20.11 из принятого API-источника добавлено семейство Languages: список содержит 16 устойчивых идентификаторов, а карточка языка даёт имя, тип, письменность и обычных носителей; документация API содержит 16 записей ([схема API](https://docs.dnd5eapi.co/api/get-a-language-by-index), [справка по языкам API](https://docs.dnd5eapi.co/reference/multilingual)). Сверка с заголовками официального SRD показала, что Languages — отдельный раздел на печатной стр. 59, поэтому все записи теперь классифицированы в `Languages`, а не `Races`, с `sourceRef` на `content/srd/languages.json` ([официальный PDF SRD 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf)).

21.11 добавлены девять названий мировоззрений и сокращений из раздела Alignment (печатная стр. 58 официального SRD 5.1): это справочные имена без повторения описаний или добавления механики. Для каждого устойчивого ID ведёт `sourceRef` в `content/srd/alignments.json`; пакет `dnd5e-2014` назначает снимку лицензию SRD 5.1 CC BY 4.0. Источник: [официальный PDF SRD 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf).

В тот же инвентарный проход добавлены три уже локально подтверждённых правила раздела Using Ability Scores: таблица и формула модификатора характеристики, бонус мастерства и преимущество/помеха. Каталог ссылается на существующие реализации в `derive.ts` и `odds.ts`; нового текста механик не добавлялось. Заголовки сверены с [официальным PDF SRD 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf).

В раздел Beyond 1st Level добавлена полная таблица Character Advancement: 20 общих уровней, пороги суммарного опыта и бонус мастерства. Снимок лежит в `content/srd/character-advancement.json`, назначен пакету `dnd5e-2014` с CC BY 4.0 и проверяется построчно в тесте каталога. Все 20 порогов и бонусов сверены с таблицей на печатной стр. 56 [официального PDF SRD 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf); значения — пороги общего уровня персонажа, не отдельные XP за уровень.

Каталог получил отдельные ссылки на 24 уже локальные правила из `sheetRules.ts`, `armor.ts`, `classes.ts`, `odds.ts`, `coins.ts` и `build.ts`: проверки навыков/спасбросков, пассивные проверки, инициативу, атаки, критические попадания, сопротивления, броню, монеты, хиты, ASI и формулы заклинаний. Это классификация существующих подтверждённых источников, не новая механика и не полный перечень прозы SRD; разделы сверяются с [официальным PDF SRD 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf).

Из раздела Multiclassing первоисточника (печатные стр. 56–57) добавлены три точные таблицы: 12 строк требований, 12 строк новых владений и 20 уровней ячеек заклинаний. Они находятся в `content/srd/multiclassing.json`, назначены слою правил пакета `dnd5e-2014` и индексируются построчно; это справочные данные, а не заявление о поддержке многоклассовых персонажей. Источник: [официальный PDF SRD 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf).

Для раздела Monsters добавлены три таблицы со стр. 255–256: кости хитов по размеру, бонус мастерства по CR и XP по CR. 74 строки таблиц имеют локальные `sourceRef`; прежняя тестовая копия XP-таблицы удалена, теперь проверка 334 SRD-монстров читает единый снимок. Значение CR 0 допускает оба официальных исхода XP (0 или 10). Источник: [официальный PDF SRD 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf).

При повторном прогоне тестов 21.11 обнаружено расхождение старой сводки с локальным компендиумом: в русских таблицах владельца есть 166 записей классовых умений, а не 222. Недостающие 56 русских строк не выдумывались. После импорта 407 исходных англоязычных умений API общий индекс содержит 573 записи обоих источников с раздельными ID и `sourceRef`.

Критерий П1 достигнут для **всего установленного локального корпуса**: основные JSON-наборы, SRD-помеченные записи компендиума, отдельные справочные таблицы, локальные правила и все снимки API имеют устойчивые ссылки. В актуальном индексе 2 115 записей; 407 API-умений классов, 38 API-черт рас и 25 наборов вариантов представлены дополнительно к локальным русским строкам и не заменяют их. Тест проверяет уникальность ID, типы, разделы, источники и зафиксированные количества; `check-packages.mjs` подтверждает, что каждый файл `content/` назначен ровно одному слою. Это закрывает классификацию уже установленных материалов, но не утверждает, что в проект импортированы все разделы/проза книги SRD 5.1.

Для будущей сверки найден отдельный локальный Foundry-экспорт метаданных: 2 085 записей с пометкой редакции 2014, из них у 24 нет лицензии; поле раздела книги не подготовлено. Это не подтверждённый полный перечень SRD и не источник для автоматического расширения каталога. Сырой экспорт и пользовательские записи в проект не копировались.

Ссылка владельца на [5e.tools/adventures.html](https://5e.tools/adventures.html) относится к каталогу приключений: страница группирует приключения и показывает метаданные вроде типа, сюжетной линии, диапазона уровней и даты публикации; SRD там выступает фильтром содержимого. Приключение — пакетный материал, а не запись правила или раздел SRD 5.1, поэтому оно не добавлялось в этот индекс.
