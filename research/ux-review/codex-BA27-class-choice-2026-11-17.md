# БА27 — выбор базового классового умения

17.11.2026. Продолжение source-aware выбора в повышении уровня. БА27 остаётся открытой.

## Изменение

- Схема импортированного выбора теперь явно различает умения базового класса и подкласса; произвольные тексты по-прежнему не разбираются автоматически.
- Добавлен точный выбор «Предмет договора» у колдуна на 3-м уровне: ровно один вариант из четырёх ID блока `predmet-dogovora` в `content/compendium/classes.json`.
- Три варианта помечены SRD, один — книжным источником; форма показывает источник каждого варианта. Сохранение оставляет source/version/layer на выбранной записи.
- Эффекты договора не подключены к расчёту. Preview предупреждает, а дальний план сохраняет этот уровень кандидатом, не выдавая неполный итог за рассчитанный.
