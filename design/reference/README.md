# Образцы владельца

Прислано 30.10.2026. Это эталон вида, а не код продукта: эмодзи, английские подписи, свои цвета и кегли меньше 8 px
здесь — так было в образце. В продукт перенесено через токены `design/tokens.json` и компоненты (TASKS Д9).

| файл | что это | куда перенесено |
|---|---|---|
| `dnd-character-card.jsx` | карта персонажа: корешок, полоса боя, ряд хитов, строка статуса, вкладки stats / gear / spells / lore, бросок инициативы | `src/components/CharacterCard.tsx`; палитра, пиксельный шрифт чисел и бронзовая черта под плитой — на всю тему |
| `dnd-character-editor.jsx` | редактор-карточка: имя и выбор расы и класса на корешке, point buy, предыстория, черты расы, навыки с отметками «предыстория» и «класс», итог | редактор персонажа `src/pages/editor/` |
| `dm-world-cards.html` | прислано пользователем 30.10.2026 вместо карточки — размеченный макет «DM World»: рейл экранов (мир, бой, книга), стопка карточек сущностей справа с вкладками и ссылками `@id`, мир клетками с владением держав по эрам и лентой эр, поход по дням с припасами, бой с инициативой и туманом, «Применить» у события с откатом | пока никуда: идея «приборы как интерфейс» — TASKS, раздел «Интерфейс: тяжесть и приборы» |
