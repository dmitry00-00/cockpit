## Решение владельца и незавершённая коррекция
Стиль и образы понравились владельцу 01.11.2026. Уточнения: Скрытность — плащ/капюшон, сапог — скорость, лук/стрелы — класс следопыта; поиск следов требует отдельного знака для контекста Выживания. Словарь — ../../ICON_SEMANTICS.md; актуальный контекст — ../../../CURRENT_CONTEXT.md.

## Художественное направление
Сливовая гамма и пропорции присланной карточки Bo Tambernack сохранены. Основа нового языка: предметная живописная графика, кожа, потёртая бронза, светлая кость, мягкая светотень и орнамент по краям главных поверхностей. Имена набраны Forum, текст PT Sans, числа Georgia. Пиксельные шрифты, сетка 16×16 и глифы предыдущего пилота в образце не используются.

Собран один законченный фрагмент: партия, подробная карточка Бо, очищенная карта Toril и нить приключения. На карточке три предметных знака по 48px; под экраном раскрывается сравнение 32/48/64px. Их силуэты сопровождаются подписями, фактура не кладётся поверх текста.

## Графика и происхождение
Пять новых оригинальных ассетов созданы отдельными вызовами встроенного image_gen: портрет Бо, знак следопыта, амулет-глаз, кожаный сапог и сливовая кожа. Промпты — prompts.json; фактические размеры, SHA256 и производные — manifest.json. Все результаты просмотрены. PNG сохранены в assets/originals; WebP для макета в assets. Три предметных знака имеют настоящий alpha, сохранённый при подготовке WebP. Для уменьшения использован установленный cwebp, не повторная генерация.

Три небольших портрета остальных участников и два предмета взяты из предыдущих художественных проб через public/art. Это контекстные материалы; новый крупный портрет и три знака являются отправной точкой текущего этюда. Локальные Forum и PT Sans скопированы из зависимостей проекта с файлами лицензий. Игровые ассеты Heroes/Diablo/Eador/Stoneshard не копировались.

Подложка — существующие очищенные тайлы Toril, не исходная карта с надписями. Выбор/маршрут — композиционный пример, не новая географическая разметка кампании. Макет предназначен для локального просмотра владельцем.

## Компоновка по высоте окна — 23.11.2026
В повторной CUA-проверке актуальной страницы при 320×700 документ и `.desk` имеют 320×700 px. Карточка занимает 296×338 px, её `scrollHeight=697`, `clientHeight=336`. Колёсико над картой не сдвигает шапку, партию, карту и нижнюю строку; прокрутка внутри карточки двигает её содержимое и показывает собственную полосу. Поэтому внешнего скролла всей страницы в текущем HTML нет. Старый `preview-narrow-historical-before-2026-11-23.jpg` был сделан до мобильной компоновки.

В том же кадре была видна обрезанная фамилия Бо. Добавлен узкий стиль до 360 px: внутренние отступы 14 px, портрет 88×112 px, промежуток 14 px, имя 29 px; ссылка CSS в HTML получила новую версию для обновления кэша. После перезагрузки `Tambernack` полностью видно. Содержимое макета — пример; игровые данные не менялись.


23.11.2026, результат повторной проверки: старый снимок действительно демонстрировал прокрутку всей страницы, но актуальный HTML в браузере её не воспроизводит. Исправлено сопутствующее обрезание фамилии на ширине 320 px. Полная приёмка БА30 по этим изменениям не закрывается: остаются native text-only 200% и полная матрица пикселей/состояний.

После повторного замечания о длинной странице мобильная `.desk` закреплена на границах viewport, а прокрутка за его пределами и touch-overscroll отключены; содержимое карточки по-прежнему прокручивается внутри неё. CSS URL получил новую версию кэша. В этой правке свежий браузерный кадр недоступен, поэтому изменение подтверждено только по стилям; предыдущие метрики CUA относятся к CSS до этого уточнения.

Независимый просмотр порядка CSS-правил подтвердил, что новые мобильные ограничения переопределяют старую трёхрядную раскладку, которая могла растягивать страницу. Если длинный скролл остаётся в открытой вкладке, следует проверить фактически загруженную ревизию CSS и внешнюю оболочку браузера; это нельзя подтвердить без актуального кадра.
