## Изменения по результатам

- `src/components/SubjectProfileShell.tsx`: русское склонение счётных единиц; ресурсы рендерятся одной строкой с названием, текущим количеством и единицей; длинные списки связанных записей сворачиваются.
- `src/entities/subjectAdapters.ts` и `src/pages/DeskPage.tsx`: профиль организации получает человекочитаемые подписи мест из справочника Toril.
- `src/entities/subjectAdapters.ts` и `src/pages/DeskPage.tsx`: профиль державы разрешает ссылки на места тем же справочником; неразрешимые записи не показываются сырыми ID.
- В предыдущем проходе тот же профиль исправлен для имён пантеонов, связанных божеств и планов.

## Ограничения приёмки

- Отображения английских канонических значений (например, `Chaotic good`, `Military`) не локализованы этой правкой; они остаются исходным текстом справочника.
- Не проверены player-mode для всей матрицы, клавиатура/Esc и возврат фокуса при переходах между всеми шестью профилями.
- CUA снимок визуально просмотрен, но не экспортирован в каталог доказательств. Проверка дерева доступности подтверждает перечисленные строки; это не замена полной визуальной матрице.
- TypeScript: `npx tsc --noEmit -p tsconfig.app.json` — exit 0. Целевые/полные тесты и build в этом проходе не запускались.

## Дополнительная проверка 06.11

Повторный read-only проход выполнен через CUA на актуальном исходнике, локальный DM-стол `http://127.0.0.1:5195/#/session/desk`, viewport 1280×720. Игровые события не создавались.

- На масштабе континента вкладка «Профиль» открывает общий shell для Faerûn. Первоначально он показывал тип «Город»; подпись теперь выбирается по масштабу, после HMR CUA подтвердила «КОНТИНЕНТ». - Для Neverwinter проверен режим «Глазами игроков» при открытой карточке «Сейчас»: дерево страницы и `document.body.innerText` не содержат `Секрет мастера`, «Только мастеру» или текст секрета про агента Zhentarim. В представлении остались дата, погода, Selûne и открытая рыночная строка.

- Развёрнутая карточка Neverwinter закрывается по Esc; после исправления `onCloseAutoFocus` CUA показала фокус на исходной кнопке «Развернуть» (проверка `document.activeElement`). Это подтверждает один маршрут города/места, не всю клавиатурную матрицу шести профилей.

После HMR проверил текст профиля: положение показывает `Столица: Suzail`, `Представленное место: Cormyr` и две связанные записи; сырых GUID/`ocr:` ID в DOM нет. Это проверяет профиль державы в DM-режиме, но не его player-mode.
- Навигация по карте и вкладкам была read-only; журнал событий и состояние кампании не менялись.

У3 остаётся открытой до полного прохода матрицы экранов, player secrecy по остальным профилям, навигации/фокуса по остальным маршрутам и полноценной визуальной проверки профиля державы. ## Дополнительный проход кода 07.11 — метки состава и campaign relations

Code review `SubjectProfileShell` показал, что отображаемые словари не покрывали все типы закрытого Subject contract. Состав державы (`organization`) и динамическое отношение (`campaign-relation`) могли отображаться внутренними slug; адаптер державы также передавал ID организации/вложенной державы как пользовательское имя, хотя индекс канонических имён уже доступен.

- `RELATION_LABEL` теперь проверяется TypeScript как полный словарь `SubjectRelationKind | SubjectCompositionRelation`; оба типа получили русские подписи. Неизвестная некорректная метка рендерится общей подписью «Связь», а не сырым внутренним ключом.
- `kingdomSubjectEnvelope` использует `relatedNames` и для организаций в составе, и для держав в `within`.
- Рендер relation теперь показывает типизированное текстовое значение рядом с целевым субъектом; это сохраняет значение campaign relation, ранее терявшееся при обходе поля target.
- Добавлен сценарий реального профиля Cormyr: `Организация: Harpers`, `Отношение фракций: Harpers campaign · 2`; тест дополнительно запрещает видимые `organization:`, `campaign-relation` и `within:`.
- `npx tsc --noEmit -p tsconfig.app.json` — exit 0; `git diff --check` — exit 0. Стандартный Vitest завис до старта теста на строке `RUN` и был остановлен. Целевой `SubjectProfileShell.test.tsx` прошёл через временный минимальный конфиг без тяжёлых общих preload/plugin hooks: 1 file, 2/2 tests, exit 0; временные конфиги удалены.
- В текущей сессии browser CUA не подключился к существующему IAB tab (`browser.user is unavailable`); native app surface сообщает заблокированный Mac. Исправление имеет компонентную проверку, но повторное открытие Cormyr в браузере и полная матрица У3 остаются незакрытыми.
