# K02 — БА2/БА20: независимая проверка интерфейса

Исполнитель: Kimi, отдельный агент проверки. Статус: подготовлено, не доставлено.
Прочитать AGENTS.md, CURRENT_CONTEXT.md и coordination/README.md. Не редактировать код.
Выход: `research/coordination/K02-independent-ux.md`, снимки `K02-*` рядом.

Проверять текущий общий baseline. Удалённый main без последних изменений не подходит.
Не читать/копировать приватные ключи и локальные сохранения; использовать собственный демосид.
Проверь зависимости и наличие локальных карт; отсутствие ресурса отмечай отдельно от дефекта UI.

Матрица:1280×720,1366×768,1512×982,1920×1080, нативный масштаб125%.
Дополнительно узкий700×720. Изменение viewport не доказывает проверку browser zoom125%.
Сценарии: раненый персонаж, концентрация, полный лист в модальном окне, снаряжение/путь,
большой шаг времени и отмена, pending-предложение с patch/без него, карта и меню слоёв,
бой и переключение выбранного персонажа, глазaми игроков, клавиатура/Esc/возврат фокуса.

Для каждого реального дефекта: серьёзность, воспроизводимые шаги, фактическое/ожидаемое,
файл/узел интерфейса, размер/режим, снимок. Проверять обрезание текста/действий, общий
horizontal scroll, фокус за пределами модального окна, тайные сведения в DOM, потерю черновиков.
Исправления не делать. Если UI не удалось запустить — не заменять визуальную приёмку чтением кода;
отдельно выдать code-review findings и точный blocker. Старые скриншоты не считать новым доказательством.

K01 может менять свой новый компонент параллельно; его интеграция ещё не входит в baseline,
поэтому не заявлять проверку будущей раскладки партии. Не менять backlog и не закрывать БА2/БА20.
Вернуть отчёт со списком проверенных и непроверенных ячеек матрицы и ограничений.

## Обязательная граница браузерной проверки
На этом Mac взаимодействие с браузером разрешено только через предоставленный платформой
инструмент computer-use/browser connector. Не запускать headless Chrome/Chromium/Playwright,
CDP, WebSocket к debug-порту или AppleScript вместо него. Не менять настройки браузера/системы.
Если в твоём наборе инструментов такого connector нет, выполнить независимый code review,
подготовить матрицу ручной проверки, а визуальные ячейки честно отметить «не проверено».
Codex отдельно выполнит браузерную приёмку через свой разрешённый инструмент.
