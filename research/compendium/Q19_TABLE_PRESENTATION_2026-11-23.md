## 24.11.2026 — уровень и условия воззваний SRD

32 воззвания в `content/srd/class-options.json` теперь связаны по точному ID с записями `content/srd/features.json`. Импортёр `import-srd-class-options.mjs` выполняет то же соединение из одной проверенной SRD-коллекции и отклоняет ссылку, если ID или `parent` не совпадают. Для каждой записи сохраняются исходные `level` и `prerequisites` без их перерасчёта. В текущем локальном наборе у 21 записи есть одно или несколько структурированных условий; у 11 список пуст.

`ClassGrid` показывает исходное поле уровня в записи SRD и известные условия типа level, feature и spell. Поле подписано «Уровень в записи SRD», поскольку оно не всегда является самым ранним уровнем фактического выбора: у двух воззваний значение 2 сочетается с требованием договора, который появляется на 3-м уровне. Перечисленные условия объединены как совместные требования. Пустой список подписан «Условия не указаны в этой записи» и не объявляется отсутствием требований. Английские названия двух Pact-умений и Eldritch Blast форматируются из точных API ID; новых совпадений с произвольными переводами нет. SRD API определяет поле `level` как уровень получения умения, но компонент не выводит из него эффективную доступность ([схема Feature](https://docs.dnd5eapi.co/api/get-a-feature-by-index)). Справочный список не выполняет выбор и не моделирует частоту выбора воззваний. Число известных воззваний остаётся в ресурсах классовой таблицы.

Данные обогащены локальным снимком SRD; сетевой импортёр, тесты, typecheck и браузер не запускались. Другие Q19-пробелы требуют отдельной модели или точного подтверждения совпадений.

## 24.11.2026 — прямые варианты выбора SRD

`ClassGrid` показывает отдельный справочный блок для 11 записей локального `class-options.json`, у которых одновременно есть числовое `subfeature_options.choose` и полный список именованных вариантов. Выводятся класс, исходное имя записи, уровень из записи SRD и «выбрать N из M»; названия вариантов раскрываются отдельно. Совпадение класса выполняется по точному `classId` с английским именем класса. Три записи Metamagic исключены из нового блока, поскольку расписание Метамагии уже показывается рядом с блоком вариантов чародея.

Срез охватывает прямые записи SRD для Fighting Style, Circle of the Land, Hunter options, Dragon Ancestor и Pact Boon. Он не объявляет записи подклассами/функциями, не вычисляет доступность и не выполняет выбор. Ряды, где список неполон или не имеет именованных ID, не показываются. Это не заполняет пробелы в книжных источниках, связях заклинаний, снаряжении Изобретателя или требованиях черт.

Статически сверены идентификаторы классов, уровни, числа выбора и длины перечней в локальном JSON. Тесты, typecheck и браузер не запускались.
