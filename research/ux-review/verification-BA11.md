# БА11 · приёмка конвейера ассетов
01.11.2026. **БА11 завершена.** Пользовательские портреты Q12 остаются отдельной задачей.

## Артефакты
- `scripts/build-art.mjs`, `design/ASSET_PIPELINE.md` — источники, размеры, происхождение, версии и рецепт.
- `public/art/manifest.json`: 24 иллюстрации, 68 WebP; версия каждого исходника/рецепта, SHA256, размеры, байты и alpha каждой производной. Исходные PNG и полные промпты остаются в design/art/bronze-atlas-v1, производственные URL на них не ссылаются.
- Версионный PNG/JSON атлас: 183 глифа; id, назначение, хеш формы/палитры, источник генератора или конкретной ручной маски. Совместимые public/icons остаются для прежних потребителей.
- Исходники 44.9 MiB → все WebP обоих направлений во всех размерах 613 386 байт (0.585 MiB). Размер самой крупной сцены B 138 522 байта. Это объём поставки изображений, не стартовые запросы.
- Runtime ArtImage не содержит исходных PNG; srcset/sizes, lazy/async, резервирование пропорций и доступный fallback. Состояния/рамки не запечены в файлы доставки.

## Проверка
36 профильных тестов прошли до финальной доработки очистки временного файла; окончательный полный прогон **1440/1440, 0 пропусков и 0 ошибок** (`/private/tmp/cockpit-BA11-full-tests.json`). Включены: соответствие кэша и реестров, сборка без кодировщика из кэша, отказ при незарегистрированном изменении оригинала, восстановление повреждённого WebP, удаление временного файла после отказа, прозрачность 0 и 123 после реального encode/decode, отсутствие увеличения маленького исходника, сохранение пропорций, ошибка и смена id, декоративный alt, отсутствие img до раскрытия галереи. Глифы/атлас проверены существующими тестами.

Сборка Vite даёт ArtSheet отдельным динамическим куском (17.27 kB, gzip 5.43 kB в первой проверенной сборке). check-art-delivery проверяет фактический dist и статический граф, наличие и контрольные суммы производных и атласа, отсутствие исходных PNG. Это не оценка полного стартового веса приложения: некоторые существующие справочники предзагружаются отдельно.

Плотность браузера может корректировать naturalWidth относительно физической ширины файла; физические размеры проверены по WebP-заголовкам.

Отдельный стенд БА9: 29 изображений (24 сравнения и 5 примерок), 29 URL WebP, 0 URL оригинальных PNG, 0 завершённых с ошибкой. Макет ширмы: портрет готов, currentSrc — 64px WebP, отображение 56×72 с предусмотренным object-fit:cover. Скриншоты BA11-gallery.png и BA11-mockup.png.
