# P7 — ограниченная связь HB-механики с runtime

Дата: 2026-11-17. Работа выполнена на изолированном снимке текущих `src/` и `content/` с baseline `7bd54fdd4d033120a18d4d3bcbdb6b8ba8c156e7`; общий грязный checkout не редактировался во время реализации.

## Контракт

- Принятый каталоговый HB-черновик остаётся описательным: `execution.executable=false`, `reviewStatus=pending-review`.
- Для runtime мастер отдельно выбирает атрибутированное поле `effect`, число и один адаптер: `damage`, `healing` или `temporary-hp`. Допускается только положительное безопасное целое; формулы кубов и другие числовые поля не применяются.
- Настройка создаётся как `WorldDelta` и меняет кампанию только после принятия. `World.activeHomebrewMechanics` хранит ссылки на исходную запись и числовой claim, поэтому версия/слой и происхождение остаются в каталоге.
- Runtime требует явный выбор цели. Используется существующее обратимое событие урона/лечения/временных хитов; проверка редьюсера сверяет активную связку, тип эффекта и точное число. В payload сохраняется `mechanicId`; текст журнала публично называет только «эффект HB» и не раскрывает ID или исходный каталог.
- Отключение также является отдельным принимаемым предложением. Уже применённые эффекты остаются в журнале и отменяются обычным undo.
- Текстовый триггер, действие, стоимость/лимит, восстановление, дальность, атака, спасбросок, состояния и длительность не исполняются. Ни одно число не выводится из прозы.

## Реализация

- `src/import/homebrewRuntime.ts` — схема связки, проверка количества, формирование предложений активации/отключения, разрешение активной записи и проверка применения.
- `src/engine/state.ts`, `src/engine/reduce.ts`, `src/engine/events.ts`, `src/engine/ladder.ts` — хранение и принятие/отмена связок; проверка события по атрибуции; исключение из map-target projection.
- `src/engine/journal.ts` — минимальная публичная подпись применения без runtime ID.
- `src/pages/desk/ToolsPanel.tsx` — мастер выбирает claim и адаптер, видит точный preview предложения, применяет эффект к выбранному актёру и отдельно предлагает отключение.
- `TASKS.md`, `CURRENT_CONTEXT.md` отражают срез и открытые ограничения.

## Проверка и ограничения

`npx tsc --noEmit -p tsconfig.app.json` на изолированном снимке завершился кодом 2 по трём исходным ошибкам вне runtime-изменений: два A5E Prestige readonly/draft присваивания в `src/engine/reduce.ts` и отсутствующая метка `A5E_PRESTIGE_UPDATED` в `src/pages/desk/helpers.ts`. Ошибок в изменённых runtime-файлах не выдал. Тесты не запускались. UI/браузер не принимались визуально.

Для следующего шага остаются отдельный dice-roll adapter с корреляцией roll/effect, другие типы механик и браузерная приёмка. Включение текущего адаптера предполагает, что мастер проверил выбранное число и отображаемый HB-текст; правило не запускается автоматически по триггеру.
